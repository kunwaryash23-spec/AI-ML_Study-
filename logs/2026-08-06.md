## Note for next session

In both notebooks the scaler is refit on the test set:

```python
X_tr, X_te = sc.fit_transform(X_tr), sc.fit_transform(X_te)
```

That leaks test statistics and is a habit worth breaking early. The correct form is:

```python
X_tr = sc.fit_transform(X_tr)
X_te = sc.transform(X_te)   # transform only — never refit on test
```

Fit on train, transform everywhere else. This applies to every preprocessing step, not just scaling.
